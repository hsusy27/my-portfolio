## 技術與功能

- **純靜態網站**：HTML / CSS / JavaScript，無後端、無建置流程，直接部署於 GitHub Pages
- **響應式設計**：桌機、平板、手機皆可瀏覽，手機版提供漢堡選單
- **專案彈窗（Modal）**：開啟時鎖定背景捲動，可切換全螢幕，底部附關閉按鈕
- **圖片放大（Lightbox）**：點擊彈窗內的截圖即可放大檢視
- **捲動淡入動畫**：區塊進入畫面時淡入
- **表格自動捲動**：彈窗內的表格在手機上可左右滑動，不會撐破版面
- **外部資源**：Google Fonts（Noto Sans TC、Inter）、Font Awesome 6
