# My Personal Portfolio & CV (v6 - Wix 經典三欄聯絡區塊版)

這是一個為資管所推甄與求職設計的韓系簡約風格個人網站。

## 版本更新 (v6)
- **聯絡我區塊重構**：將底部的「聯絡我」改為與 Wix 範本完全一致的 **Call / Write / Follow** 三欄式佈局，包含電話、Email 連結，以及美觀的社群圖示按鈕 (Facebook, Twitter, LinkedIn, Instagram)。
- 支援手機與桌面 RWD 響應式排版。

## 資料夾結構
- `index.html`: 網站主程式
- `assets/css/style.css`: 樣式表
- `assets/js/main.js`: 互動腳本
- `assets/img/`: 存放頭像、證照照片、專案截圖
- `assets/video/`: 存放專案操作示範影片 (`.mp4`)
