台灣半導體產業鏈商業智慧看板

端到端半導體決策系統技術白皮書

圖：放置 BI 儀表板截圖

開發背景

市面上的財經平台多半聚焦於單一個股，缺乏對供應鏈上下游的宏觀產值結構分析。本專案旨在打造一套端到端（End-to-End）的半導體商業智慧決策系統，無縫切換巨觀產業趨勢與微觀個股分析。

系統架構與資料流

  • 萃取與轉換：透過 API 批次下載歷史日線與月營收。利用 Pandas 清洗空值並計算 MoM、YoY 衍生欄位。
  • 冪等性寫入：採用 INSERT OR REPLACE 語法與複合主鍵，確保 ETL 排程寫入不會重複。
  • 資料庫設計：採用 SQLite 3NF 與星型模型 (Star Schema)，將維度表與事實表解耦。
  • 查詢優化：建立降序索引，並利用 SQL 視窗函數 (AVG() OVER) 進行計算下推，實現毫秒級查詢。

UI/UX 設計

導入現代前端設計系統概念，透過自訂 CSS 與 Streamlit 渲染響應式介面，營造出具備視覺層級的高質感 SaaS 體驗。

AIRIC 新聘人員資格審核與簽呈生成系統

雙軌審核架構，大幅縮短行政流程

圖：放置審核系統截圖

解決的問題

過去新聘案需人工比對履歷與論文，單案耗時 30–45 分鐘。本系統將審核流程自動化，並透過「預設規則＋自訂條款」架構，快速產製公文草稿，將時間縮短至 5 分鐘內。

技術架構

  • 純靜態網頁部署於 GitHub Pages，無需後端，提升資安與個資保護。
  • 雙軌引擎：本機正規表達式引擎與 Gemini API 語意分析並用。
  • 多檔案解析：整合 PDF.js、FileReader API 及 Base64+Gemini 多模態 OCR。
  • 非同步佇列控管 (Promise.all) 確保多附件文字不亂序。

AI工具便利性與使用依賴傾向之探索性研究

量化問卷與統計分析研究計畫

圖：放置統計圖表或量表架構圖

研究動機

在導入 AI 工具時，觀察到「工具越便利、使用者越少主動查證」的現象。基於 TAM 理論之認知易用性與認知卸載概念發起此研究。

研究設計與發現

  • 自編 Likert 5 點量表，透過便利抽樣與滾雪球抽樣回收 55 份成人有效樣本。
  • 運用 Cronbach's α 信度檢驗、Pearson 相關分析與單因子 ANOVA 進行分析。
  • 核心發現：便利性認知會顯著提升使用頻率，進而強化依賴傾向；依賴傾向與「拖延/專注力下降」及「認知卸載」呈顯著中高度正相關。
  • 醫療相關工作者之依賴傾向平均分數顯著較高。

yuan — 個人工作待辦與日誌匯出系統

簡化工作彙報的輕量化工具

圖：放置 yuan 系統畫面截圖

開發背景與功能

為了解決過去使用 Notion 記錄工作時，需手動整理進度報告的繁瑣流程而開發。本系統整合了待辦事項管理，並支援依指定時間區間匯出工作日誌 PDF，方便交由 AI 輔助生成進度簡報。

此系統完全於客戶端運行，資料加密儲存於瀏覽器，兼顧隱私與便利性。
