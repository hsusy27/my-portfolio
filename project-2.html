人機互動與使用者依賴度研究

結合 Python 數據分析與學術研究方法，探討人類與 AI 協作的影響。

研究動機與目的

在醫療 AI 領域工作期間，我觀察到使用者在面對人工智慧輔助決策時，容易產生過度依賴或信任的問題。因此，我針對「人類與 AI 互動模式及依賴效應」展開獨立的量化行為研究，作為申請研究所的學術研究計畫基礎。

研究方法與工具

  • 數據收集: 設計並發放結構化問卷，回收共 55 份有效樣本數據。
  • 數據清理: 使用 Python (Pandas) 進行資料前處理、缺失值處理與格式轉換。
  • 量化分析: 透過敘述性統計與推論性統計，分析使用者在不同情境下的依賴程度差異。

研究發現與未來展望

初步分析結果顯示，使用者在面對高風險決策與低風險決策時，對 AI 系統的依賴度有顯著差異。此專案展現了我具備獨立進行文獻回顧、問卷設計以及利用 Python 處理資料的研究潛力。未來進入資管所後，希望能進一步擴大樣本數，並深入探討介面設計如何減緩使用者的過度依賴。
