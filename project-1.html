專案背景與動機

在人工智慧中心的實務工作中，新進人員的報到與資格審核流程繁瑣。為了將行政流程數位化與自動化，我決定利用下班時間進修的程式技能，親手打造一套內部使用的審查系統，以降低溝通成本並提升效率。

使用技術

  • 前端框架: React (構建可重用的元件化介面)
  • 樣式設計: Tailwind CSS (快速實現響應式與客製化版面)
  • UI/UX 規劃: Figma (前期 Wireframe 與視覺原型設計)
  • 部署方式: 透過 GitHub Pages 進行本地/靜態網頁部署

專案成果與貢獻

透過自行設計的互動式表單與狀態管理，成功將原本依賴紙本與人工核對的流程轉移至網頁端。此專案不僅展現了我的前端開發能力，更證明了我具備從「發現痛點」到「實作解決方案」的完整跨領域系統規劃能力，符合資訊管理所著重的實務精神。
